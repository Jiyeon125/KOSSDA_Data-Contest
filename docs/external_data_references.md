# 외부데이터 출처·인용 (External Data References)

> 본 분석의 **배경·교차검증**에 인용한 외부 집계/공식조사 출처를 모은다.
> 공모전 규정상 데이터 활용 시 **출처(URL/DOI)** 를 명시해야 하며,
> KOSSDA 소장자료는 **KOSSDA 자료인용서식**(자료별 메타데이터)을 따른다.

---

## 0. 공모전 데이터 조건 (확인)

- 2차 데이터 활용 + **1건 이상 KOSSDA 소장 데이터** 필수.
- **[특별상 트랙] SRC가 KOSSDA에 기탁한 데이터 1건+ 필수 → KGSS** 활용 시 **「한국종합사회조사(KGSS)상」** 응모 자격.
- 우리 보유 KOSSDA 소장 데이터 = **① KGSS(한국종합사회조사, SRC 기탁) ② KLIPS(한국노동패널)**.
  → 필수조건·특별상 트랙 모두 충족. **KGSS는 본편 기둥(10단계·fig24), KLIPS는 보조검증(9단계·fig09)**.
- **청년삶실태조사·경제활동인구조사(EAPS)** 는 KOSIS/MDIS 경로(메인 미시분석·배경). KOSSDA 소장 여부는
  추가 확인 권장(있으면 DOI 추가 인용).

## 1. 보건복지부 「2023년 고립·은둔 청년 실태조사」 — 5단계 교차검증 ⭐

- 수행: 보건복지부·한국보건사회연구원(KIHASA), 책임 김성아. 발표 2023.12.13.
- 보고서: 『김성아 외(2023). 고립·은둔 청년 실태조사 연구, 보건복지부·KIHASA(용역보고서 2023-124)』
- RAW DATA: 공공데이터포털 `보건복지부_고립_은둔 청년 실태조사` (data.go.kr/data/15156074/fileData.do)
- **핵심 수치(우리 결과와 비교)**:
  - 고립·은둔 청년 **삶만족 3.7점** vs **전체 청년 평균 6.7점**
    → 우리 청년삶2024 쉬었음 내부: 은둔없음 **6.70** ≈ 6.7, 장기은둔(7년+) **3.75** ≈ 3.7 (fig23 수렴).
  - 전국 고립·은둔 청년 **최대 약 54만 명** 추정.
  - 자살 생각 75.4%, 자살 시도 26.7%. 본인을 하층으로 인식 75.7%.
  - 고립 시작 계기: 취업 실패·대인관계. 필요 지원 1순위 경제적 지원(88.7%).

## 2. 한국고용정보원 「청년 니트(NEET)의 구성 변화와 노동시장 유입 촉진 방안」(2025.05) — 1단계 배경 ⭐

- 통계청 **경제활동인구조사 원자료**를 OECD 기준으로 재산출.
- 한국 청년(15~29) NEET: **2014 17.5% → 2020 20.9% → 2021 20.0% → 2022 18.3%**.
- OECD 평균: 2014 15.7% → **2022 12.6%**. 한국은 비교 11개국 중 **2014 대비 증가한 유일국**, 2022년 **3위**.
- 전체 규모는 청년인구 감소로 2008년 156.2만 → 2024년 125.3만이나, **비구직형(구직 안 함) 니트만 증가** = 질적 고착.
  → 우리 1~2단계(실업률↓인데 쉬었음↑)와 정합. (fig00)

## 3. 청년삶실태조사 공식 '고립·은둔' 비율 (참고)

- 국무조정실·KIHASA 발표: 고립·은둔 청년 비율 **2022 2.4% → 2024 5.2%** (2배 증가).
- 주의: 이 공식 비율은 외출·관계·은둔 문항 **복합 정의**라 우리가 쓴 `seclusion_duration`(은둔 지속기간)·
  `outing_freq`(외출빈도) 단일 변수와 **정의가 달라** 수치 직접대조는 하지 않음(방향 참고만).

## 4. KOSSDA 소장 — KGSS (본편 기둥 · KGSS상 트랙) ⭐

- 한국종합사회조사(KGSS) 2003–2025 누적자료, 성균관대학교 서베이리서치센터(SRC) 수행 / **KOSSDA 소장(SRC 기탁)**.
- **자료인용서식(공모전 예시 그대로)**:
  > 김지범. 한국종합사회조사, 2003-2025 [누적자료] [데이터 세트]. 성균관대학교 서베이리서치센터 [연구수행기관]. 한국사회과학자료원(KOSSDA) [자료제공기관], 2026-03-27, https://doi.org/10.22687/KOSSDA-A1-CUM-0074-V1.
- 본 프로젝트 활용 범위: 2021·23·25 통합(N=3,489), 가중 FINALWT. **취업 여부보다 고립(믿는 친구 0명)이 행복을 더 가른다**는
  전국 일반화(fig24). 부록: 친구수 용량반응(fig25)·외로움→우울 수렴(fig26, 2012).

## 5. KOSSDA 소장 — KLIPS (보조검증 데이터)

- 한국노동패널조사(KLIPS) 26차(2023년 조사), 한국노동연구원. KOSSDA 소장(시리즈: Korean Labor and Income Panel Study).
