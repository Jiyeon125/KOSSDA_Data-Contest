# 사회통합실태조사 추가 분석 설계 (선행 설계 문서 — 데이터 미확보 상태)

> 2026-06-11 작성. **아직 데이터를 받지 않았으며, 이 문서는 확보 시 바로 분석에 들어가기 위한 설계서다.**
> 목적: KGSS 일반화(S7)를 보강하는 **'청년 고립의 연간 추세'** 트랙 추가. 서사를 흔들지 않는 보조 증거로만 사용한다.

## 1. 왜 이 데이터인가

- **KOSSDA 기탁 확인됨**: 한국행정연구원이 2013년부터 매년 시행하는 국가승인통계로, KOSSDA에 연도별 기탁
  (2018/2019/2020 기탁 보도 확인; 이후 연도는 KOSSDA 검색에서 확인 필요).
- 본 프로젝트의 약점 보완: KGSS는 격년(2021·23·25)·청년 부분표본 과소 → 사회통합실태조사는 **매년 조사 + 표본 약 8,000명**으로
  청년(19–34) 부분표본도 연 1,500명 안팎 기대 → **청년 고립·웰빙의 연간 추세**를 그릴 수 있다.
- 핵심 문항(연도별 문항 번호는 코드북에서 확인):
  - **사회적 고립**: "몸이 아파 집안일을 부탁할 사람 / 큰돈을 빌릴 사람 / 우울할 때 이야기할 상대"가 있는지 (3문항 — 통계청 사회조사와 유사한 관계적 고립 측정)
  - **외로움**: "외롭다고 느끼는 정도" (사회적 고립감 문항군)
  - **주관적 웰빙**: 삶의 만족(0–10), 행복(0–10), 근심·걱정
  - **신뢰·소통**: 대인 신뢰, 사회적 소통 인식
  - 인구통계: 연령, 경제활동상태(취업 여부)

## 2. 연구 질문 (보조 트랙)

- **RQ-A.** 청년(19–34)의 관계적 고립(의지할 사람 없음) 비율은 최근 5~10년간 어떻게 변했는가?
  → 청년삶 2022→2024의 "도움없음 3.5→8.4%" 악화 추세가 **독립 조사에서도 재현되는가**.
- **RQ-B.** 청년 내에서 고립 여부에 따른 웰빙 격차는 취업 여부에 따른 격차보다 큰가?
  → KGSS 결과(고립 Δ0.317 vs 취업 Δ0.023)의 **연간·청년 한정 재현**.

## 3. 데이터 확보 경로

1. KOSSDA(kossda.snu.ac.kr) 검색: "사회통합실태조사" → 최신 연도부터 3~5개 연도 신청 (회원가입 + 이용신청, 통상 즉시~수일).
2. 대안: 한국행정연구원 KSDC/공공데이터 경로. **KOSSDA 경로를 우선** (공모전 KOSSDA 소장 데이터 추가 활용 → 인용서식·DOI 확보 용이).
3. 받은 파일은 `data/raw/social_cohesion/` 에 연도별로 두고, 코드북은 `data/codebook/`.

## 4. 파이프라인 통합 설계 (기존 구조 재사용)

```
data/raw/social_cohesion/*.sav|csv
  → src/preprocess.py 에 build_social_cohesion() 추가
     - 연도별 파일 로드(인코딩/포맷 자동 처리, pyreadstat 재사용)
     - 변수 매핑: year, age, youth(19–34), employed, isolation_flag(3문항 중 1개 이상 '없다' 또는 전부 '없다' — 코드북 확인 후 확정),
       lonely, life_satisfaction, happiness, weight
     - ⚠ 코드값(1/2, 9 등)은 코드북 확인 전 임의 해석 금지 (프로젝트 원칙)
  → data/processed/social_cohesion_youth.csv (청년만, 연도 long)
  → src/build_db.py 적재 (테이블: social_cohesion_youth)
  → scripts/cohesion_trend.py (신규)
     - RQ-A: 연도 × 청년 고립 비율 (가중) 라인차트 → outputs/figures/27_cohesion_isolation_trend.png
     - RQ-B: 연도 풀링 후 고립/취업 × 웰빙 MWU + 효과크기 → 요약 csv (kgss_isolation_summary.csv 방식 재사용)
  → app.py S7(KGSS) 하단 expander "보조: 사회통합실태조사 연간 추세"로 게시
```

## 5. 분석 방법 (기존 원칙 그대로)

- 가중 비율로 추세 제시, 검정은 비가중 MWU/카이제곱 + 효과크기.
- 고립 정의가 청년삶(행동)·KGSS(친구)·사회통합(도움 가능 3문항)으로 **모두 다름** → "서로 다른 측정에서의 방향 일치"
  프레임 유지(소논문 v2 §6.3과 동일). 측정 차이를 숨기지 말고 명시.
- 연도 간 문항 변경 여부를 코드북에서 반드시 확인(척도 변경 시 해당 연도 제외 — D9 원칙 재사용).
