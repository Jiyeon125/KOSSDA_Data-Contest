| 항목 | 결정 |

| 가중치 | 쉬었음 내부(N=1,062) 분석은 **비가중**(중간발표·소논문 수치 연속성), 모집단 규모 환산만 가중 |

| KOSSDA 요건 | KGSS(기둥)·KLIPS(보조)는 공모전 필수 활용 요건이므로 **무조건 유지** |

## 1. 교집합 (양쪽 공통 — 머지 시 자동 보존)

- 메인 데이터: 청년삶실태조사 2024, **쉬었음 N=1,062 동일 표본** (양쪽 모두 동일 정의로 도달)
- EAPS 연령별 쉬었음 추이 = 배경/문제 제기
- 비모수 검정: Mann-Whitney U(연속형), 카이제곱/Fisher(범주형), 소표본 검정 생략
- 0-팽창 변수(부채·이자·이전소득) → 평균 금지, **보유율 + 보유자 중앙값**
- 가족 안전망 분석, '도움받을 곳 없음'을 핵심 취약 축으로 취급
- null finding 정직 보고, 횡단면 자료 인과 해석 금지
- 부채/이자/이전소득 보유 플래그 파생

## 4. 머지 후 앱 구조 (S0~S9)

```
S0 개요·KPI(위험군 23.0% 추가) → S1 배경(EAPS + 쉬었음≠실업자)
→ S2 무엇으로 버티나(보유율·보유자 중앙값 표 + 가족 편중)

```

## 7. 이번 업그레이드의 의의·특장점 + 추가 분석 계획

**의의·특장점**
1. **수치 완전 재현**: 팀원 분석 전 항목을 독립 파이프라인에서 재현(§5) → 발표 수치의 신뢰성·재현성 입증.
2. **방법론 상향**: p값만 있던 검정에 효과크기 병기, 기대빈도<5 시 Fisher 자동 전환(`queries.py`).
3. **서사 완결**: "안전망 격차 → 유형 분화 → 가장 깊은 곳(고립) → 전국 일반화 → 시계열 악화"로
   두 레포의 발견이 하나의 이야기로 연결됨(S5의 유형×웰빙이 다리).
4. **KOSSDA 요건 충족 유지**: KGSS·KLIPS 활용이 그대로 살아 공모전 자격·KGSS상 트랙 유지.
5. **데이터 거버넌스**: 원자료·DB 비커밋 원칙 유지(팀원 레포의 DB 커밋 방식 미채택).
