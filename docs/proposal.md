# 기획서 (Proposal)

## 1. 프로젝트명

청년 '쉬었음' 집단의 내부 취약성 분석

## 2. 추진 배경

- 노동시장에서 '쉬었음'으로 분류되는 청년 인구가 증가하는 추세.
- '쉬었음'은 실업/학업/육아 등과 구분되는 모호한 상태로, 정책 사각지대에 놓이기 쉬움.
- 단일 집단으로 보기 어려운 이질적 집단이라는 점에 주목.

## 3. 목적

- '쉬었음' 청년 집단을 내부 구조를 가진 집단으로 보고, 하위 유형별 취약성 차이를 시각화.
- 정책 우선 개입 대상 후보를 데이터 기반으로 제시.

## 4. 분석 질문 (요약)

1. 하위 유형 구분 가능성
2. 유형별 취약성 차이
3. 장기 쉬었음으로 이어지는 특성
4. 우선 개입 대상

## 5. 사용 데이터 (예정)

- KOSSDA 제공 청년 관련 조사 데이터 *(명칭/출처 추후 확정)*
- 대상: 청년층 중 '쉬었음' 응답 사례

## 6. 산출물

- Streamlit 기반 인터랙티브 대시보드
- 분석 보고서 / 발표 자료
