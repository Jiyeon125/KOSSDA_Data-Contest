# 분석 계획 (Analysis Plan)

> ⚠️ **(과거 초안)** 본 문서는 데이터 확정 전 초기 계획이다. **확정 분석설계·통계검증은
> `docs/research_design.md`, 테이블 현황은 `docs/table_design.md`, 전처리는 `docs/preprocessing_plan.md`**
> 가 최신·정본이다. 이 문서는 초기 의사결정 기록으로만 보관한다.
> (이후 추가: 데이터기반 군집 하위유형, 2022↔2024 재현성 비교 — 정본 문서 참조.)

## 1. 데이터 파이프라인

```
data/raw  →  preprocess.py  →  data/processed  →  build_db.py  →  data/db/*.sqlite3  →  queries.py  →  charts.py  →  app.py
```

## 2. 단계별 계획

### (1) 데이터 점검
- `notebooks/01_data_check.ipynb` 에서 컬럼/결측/분포 확인.
- 분석 대상(청년 '쉬었음' 응답) 필터 기준 정의.

### (2) 전처리 (`src/preprocess.py`)
- 결측치 처리, 컬럼명 정리, 타입 변환.
- 분석용 파생 변수 생성 (예: 쉬었음 기간 구간화).

### (3) DB 구축 (`src/build_db.py`)
- 전처리/원본 CSV → SQLite 테이블 적재.

### (4) 조회 (`src/queries.py`)
- 분석 질문별 집계 쿼리 작성.

### (5) 시각화 (`src/charts.py`, `app.py`)
- 하위 유형별 취약성 비교 차트.
- Streamlit 대시보드 구성.

## 4. 청년삶실태조사 2024 변수 매핑 (코드북 확정)

> 출처: `data/raw/youth_life/2024_총괄_20260527_89328.csv` (15,098행 × 447열, **cp949 인코딩**)
> 코드북: `data/codebook/2024년_청년삶실태조사_파일설계서.xlsx` ('통합' 시트)에서 확인.
> 아래 값은 코드북으로 확정된 코드 정의이며, 표본 수는 실제 데이터에서 계산한 값이다.

### 4-1. 쉬었음 필터 (확정)

```
경제활동상태 == 8 (비경제활동인구)
AND
지난 주 주된 활동 상태 == 10 (쉬었음)
```

- **경제활동상태**: 1 상용근로자 / 2 임시근로자 / 3 일용근로자 / 4 고용원 있는 자영업자 /
  5 고용원 없는 자영업자 / 6 무급가족종사자 / 7 실업자 / **8 비경제활동인구**
- **지난 주 주된 활동 상태**: 1 육아 / 2 가사 / 3 정규교육기관 통학 / 4 입시학원 통학 /
  5 취업학원·기관 통학 / 6 취업준비 / 7 진학준비 / 8 질병 등 요양 / 9 군입대 대기 /
  **10 쉬었음** / 11 기타 (취업자·실업자는 결측)

**표본 수 (실제 계산)**: 전체 15,098명 → 비경제활동 4,029명 → **쉬었음 청년 1,062명**

### 4-2. 분석 변수 (실제 컬럼명)

| 구분 | 실제 컬럼명 | 비고 |
| --- | --- | --- |
| 인구 | `성별`, `연령별`(1:19~24·2:25~29·3:30~34), `부모 동거 여부`(1 예·2 아니요) | |
| 생활경제 | `월 평균 총생활비`, `청년 연간소득 - 총 소득`, `사적 이전소득`, `공적 이전소득` | 연속형 |
| 금융부담 | `청년 기준 부채 총액`, `생활비 부채`, `월평균 이자`, `학자금 부채`, `주택관련 부채` | 연속형 |
| 생활안전망 | `(복수 응답) … 이번 달 생활비가 부족할 때_(1)가족~(5)없음` | **0/1 코딩**(1=해당) |
| 인식 | `삶에 대한 전반적 만족도`(0~10), `삶의 행복감 정도`(0~10), `주관적 계층 인식`(1 하층~5 상층) | |

### 4-3. 경제활동인구조사 / KLIPS 메모
- **경제활동인구조사(eaps)**: KOSIS 집계표(소형 xlsx)라 별도 코드북 없음 — 정상. 배경 현황 시각화용.
- **KLIPS**: 1998~2023 전 웨이브 보유. 전체 병합 금지. 최근 웨이브(2023=klips26 p/h) 중심으로 보조 검증에만 사용. 코드북은 `data/codebook/`에 별도 보관(DB 적재 X).

## 5. 주의사항
- 임의 수치 생성 금지. 모든 결과는 실제 데이터 기반으로만 산출.
- 코드값은 반드시 코드북(`data/codebook/`) 확인 후 해석. 9·99·999 등 임의 결측 처리 금지.
- (현행) 앱에는 sample 영역이 없으며, 전 수치는 실제 DB 테이블 기반이다.
