# 분석 계획 (Analysis Plan)

> 실제 데이터 확정 전 계획 초안입니다. 구체 변수/방법은 데이터 확인 후 갱신합니다.

## 1. 데이터 파이프라인

```
data/raw  →  preprocess.py  →  data/processed  →  build_db.py  →  data/db/*.sqlite3  →  queries.py  →  charts.py  →  app.py
```

## 2. 단계별 계획

### (1) 데이터 점검
- `notebooks/01_data_check.ipynb` 에서 컬럼/결측/분포 확인.
- 분석 대상(청년 '쉬었음' 응답) 필터 기준 정의.

### (2) 전처리 (`src/preprocess.py`)
- 결측치 처리, 컬럼명 정리, 타입 변환.
- 분석용 파생 변수 생성 (예: 쉬었음 기간 구간화).

### (3) DB 구축 (`src/build_db.py`)
- 전처리/원본 CSV → SQLite 테이블 적재.

### (4) 조회 (`src/queries.py`)
- 분석 질문별 집계 쿼리 작성.

### (5) 시각화 (`src/charts.py`, `app.py`)
- 하위 유형별 취약성 비교 차트.
- Streamlit 대시보드 구성.

## 3. 분석 질문별 접근 (초안)

| 질문 | 접근 방법(예정) | 산출 시각화(예정) |
| --- | --- | --- |
| 하위 유형 구분 | 군집/교차분석 | 그룹별 막대그래프 |
| 유형별 취약성 차이 | 집단 비교 | 비교 막대/박스 플롯 |
| 장기화 특성 | 기간별 비교 | 추세/누적 차트 |
| 우선 개입 대상 | 취약성 종합 | 순위 표/히트맵 |

## 4. 주의사항
- 임의 수치 생성 금지. 모든 결과는 실제 데이터 기반으로만 산출.
- 현재 앱의 수치는 모두 sample 임을 명시.
