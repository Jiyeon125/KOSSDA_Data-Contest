# 시각화 전략 (Visualization Strategy)

> 목적: Streamlit 대시보드 + 공모전 PPT 의 그래프 구성을 **확정**한다.
> 원칙: 제안서 6단계 흐름을 그대로 따라가며, **쉬었음 청년 '내부'의 생활안전망 격차**를 클라이맥스로 둔다.
> 모든 수치는 `src/queries.py` 를 통해 DB(`youth_life_2024_analysis`, `eaps_labor_status_summary`, `klips_youth_2023`)에서 가져온다. 하드코딩 금지.

| 색상(안전망) | 비공식(가족·지인)=`#4C78A8`(안정) · 공식(공공·민간)=`#F58518`(부채압박) · **없음=`#E45756`(사각지대)** |

## 1. 섹션별 차트 구성 (대시보드 흐름 = 제안서 흐름)

### S0. 개요 · 핵심 요약 (Hero + KPI)
- **메시지**: "노동시장 밖 쉬었음 청년, 그 안에 사각지대가 있다"
- **시각화**: KPI 카드 4개
  - 청년 쉬었음 규모 `약 70만 명`(가중) / 쉬었음 비율 `7.2%`
  - 도움받을 곳 없음 `약 5.9만 명`(8.4%)
  - 고취약(3점+) `약 11%`
- **데이터**: `weighted_share`, `numeric_summary`

### S1. 배경 — 실업률만으로는 부족하다 (EAPS)
- **메시지**: 실업률은 안정돼 보여도 '쉬었음'은 구조적으로 증가
- **차트**: 라인(이중축) — 청년(15-29) **실업률(%)** vs **쉬었음 인구(천명)** 2003~2025
- **데이터**: `eaps_labor_status_summary` (indicator='실업률','쉬었음', age='15 - 29세')
- **인터랙션**: 연령대 토글(계/15-29/30-39)

### S2. 쉬었음은 누구인가 — 실업자와 다르다
- **메시지**: 쉬었음 ≠ 실업자 (별개 집단)
- **차트**: 4집단 grouped bar 2종 — ① 주관 웰빙(삶만족·행복·계층) ② 취약지표(부채·고립·도움없음)
- **통계 배지**: 쉬었음 vs 실업자(삶만족 p<.001), 쉬었음 vs 취업자(취약점수 r=.26)
- **데이터**: `group_means`, `chi_square_compare`, `mann_whitney_compare`

### S3. 쉬어도 생활비는 든다 — 무엇으로 버티나
- **메시지**: 다수(85%)는 가족지원망으로 버틴다
- **차트**: 생활비 지원망 100% 누적 막대 or 도넛 (가족/지인/공공/민간/없음) — 쉬었음 vs 취업자 비교
- **데이터**: `weighted_share`(help_living_*)

### S4. ★핵심★ 쉬었음 '내부'의 생활안전망 격차
- **메시지**: 같은 쉬었음이라도 **두 갈래 취약**으로 갈린다
- **차트 A**: 안전망 유형 분포 막대 (비공식/공식/없음) + 모집단 추정 라벨
- **차트 B**: 유형별 격차 grouped bar — `없음`=고립형(고립 12.1%), `공식`=부채압박형(부채 38.5%)
- **통계 배지**: 없음 vs 비공식 (고립 p<.001 ⚠소표본, 계층 p=.035)
- **데이터**: `weighted_group_share`, `weighted_share`/`weighted_mean`, `safety_net_type`

### S5. 취약은 누적된다 — 스펙트럼
- **메시지**: 취약요소가 쌓일수록 웰빙이 유의하게 낮아진다
- **차트**: ① vuln_score 분포 히스토그램(0~6) ② 고취약(3+) vs 저취약 웰빙 비교 막대
- **통계 배지**: 삶만족 p=.006 / 계층 p=.0004
- **데이터**: `vuln_score`, `mann_whitney_compare`

### S6. 보조검증 (KLIPS, 2023) — 약한 근거 + 한계 명시
- **메시지**: 다른 패널에서도 '비취업 청년 가구 부채부담 ↑' 경향 (단, 쉬었음 단독 식별 불가)
- **차트**: KLIPS 취업 vs 미취업 가구 부채보유율 막대 + **⚠ 소표본/회고형 배지**
- **데이터**: `klips_youth_2023`

### S7. 결론 · 정책 함의
- **메시지**: '도움없음' 사각지대(약 5.9만 명)와 '공식의존 부채압박형'을 구분 타게팅
- **시각화**: 요약 카드 + 한 장 종합 도식(텍스트 중심)

## 3. 구현 순서 (사용자 합의)
1. **시각화 전략 확정** (이 문서)
2. **1차 대시보드**: S0~S6 기본 차트 + queries/charts 연결 ✅
3. **분석 보강**: 청년삶 2022 비교(추세/재현성), 쉬었음 내부 군집화(취약 하위유형) ✅
4. 보강 결과 **대시보드 반영** ✅
   - **S4 개정**: 임의 `safety_net_type` 대신 **데이터기반 군집(K-means k=3)** 하위유형
     (안정형/사회적 고립형/부채압박형)을 전면화. 규모·특징 프로파일·웰빙 + KW/MWU 검정.
     휴리스틱 typology는 expander '참고'로 강등.
   - **S7 신설**: 재현성·추세(2022↔2024) — 쉬었음 비중, 내부 취약지표(연도 카이제곱),
     2022 군집 재현. (기존 결론은 S8로 이동)

## 4. 보류/주의 (대시보드에 명시할 한계)
- `future_feasibility`(미래전망) 값 방향 코드북 확인 전까지 강한 해석 보류
- `없음`·`공식` 유형, 고립 셀은 소표본 → 검정보다 기술통계 + ⚠배지
- KLIPS 소득은 회고형(작년) → 단독 해석 주의
