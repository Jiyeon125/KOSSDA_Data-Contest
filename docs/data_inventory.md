# 데이터 인벤토리 (Data Inventory)

> `data/raw/` 와 `data/codebook/` 의 실제 파일을 직접 열어 구조를 확인한 결과다.
> 행/열 수는 실제 측정값이며, 의미가 불확실한 경우 "추정" 또는 "확인 필요"로 표기했다.
> 코드북(파일설계서/오픈코드북)은 **분석 데이터가 아니며 DB에 적재하지 않는다.**

## 3. 즉시 사용 가능성 판정

- **바로 분석 가능**: 청년삶 2024 CSV (인코딩·구조·코드값 확정). 이미 `youth_2024_all/rested` 로 전처리됨.
- **배경 시각화 가능**: EAPS 3종 집계표(연도 wide → long 변환만 하면 사용 가능).
- **구조는 확인됨, 변수 해석 추가 필요**: KLIPS 26p/26h (키·행열수·변수명 패턴 확정. 단, `p26####` 개별 변수의 의미는 `개인용` 코드북 변수설명 열을 추가 파싱해야 확정 → §variable_candidates 에서 "확인 필요"로 표기).
