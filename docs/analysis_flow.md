# 분석 흐름 — 단계별 확정 기록 (Analysis Flow Log)

> **운영 방식**: 분석 → 인사이트 → (사용자 검토·확정) → 다음 분석 → … 으로 한 단계씩 진행한다.
> 각 단계는 **시각자료 1개 + 읽은 인사이트**를 사용자와 확정한 뒤에만 기록한다.
> 단계가 확정될 때마다 이 문서에 추가하고 `scripts/auto_commit.py` 로 기록·커밋한다.
>
> **중요 방침(번복)**: 이전에 진행한 "쉬었음 내부를 3군집으로 묶는다"는 결론은
> 자연스러운 군집이 없어(실루엣 단조증가, 웰빙 차는 고립형에서만 유의) **과장으로 판단, 폐기**.
> 쉬었음 내부는 "연속적 취약 스펙트럼 + 질적으로 분리되는 사회적 고립형 고위험군"으로 재구성한다.
> (해당 단계에서 시각자료로 재확정 예정.)

## 1단계 · 배경: 청년 '쉬었음' 증가 — ✅ 확정

- **시각자료**: `outputs/figures/01_eaps_rested_trend.png`
- **데이터/집계**: EAPS 쉬었음 집계표(2003~2025), 연령밴드 **15–29세·30–39세만**
  표시(전 연령 '계'는 40·50·60대 포함이라 청년 분석을 가려 제외).
- **인사이트(확정)**:
  - 15–29세 약 227천 → 428천, 30–39세 약 115천 → 310천 — 둘 다 **장기 우상향**.
  - **2019–2020 급등 후 고착**(안 내려옴).
  - → '쉬었음'은 일시현상이 아니라 청년층에서 **구조적으로 커지는 문제**. 주제의 출발점.
- **주의**: 19–34는 15–29+30–39의 합·평균이 아님(EAPS엔 19–34 밴드 없음). 19–34 실측은
  청년삶(2022·2024)에 있으나 출처·정의가 달라 배경 그래프에는 EAPS만 둔다.

## 4단계 · 쉬었음은 무엇으로 버티는가 — ✅ 확정 (재설계)

- **시각자료**: `outputs/figures/04c_rested_survival.png` (쉬었음 1,062명 기준)
- **인사이트(확정)**:
  - 생활 유지는 **압도적으로 가족 중심**: 부모와 동거 **72.6%**, 생활비 부족 시 가족 도움 가능 **85.3%**.
  - 공적·제도 안전망은 미미(공공 3.9%·민간 1.0%), 지인 14.1%.
  - → 쉬었음이 평균적으로 안정돼 보이는 건 돈이 많아서가 아니라 **가족이 떠받쳐서**(착시).
  - → 다음 질문: **그 가족 울타리가 없거나 흔들리면?**
- **가설 재정립**: "쉬었음의 평균적 안정 = 가족 안전망이 만든 것 → 위험은 평균이 아니라 그 망이 약한 내부 소수에 집중."

### (보강실험) "가족 도움 가능"이 곧 안전은 아니다 — ✅ 확정
- **시각자료**: `outputs/figures/20_rested_safety_tiers.png` (`scripts/rested_safety_layers.py`)
- 안전망 등급 3단(상호배타): 견고(도움가능·위험요인X) 6.57 > 조건부(도움가능·위험요인O) 6.32 > 취약(도움없음) 6.01.
- 3등급 차 **유의**(Kruskal-Wallis p=0.035). → '도움 가능' 응답만으로 안전 단정 불가(조건부<견고).
- **정직한 한계**: 견고 vs 조건부 p=0.054(경계)·r=-0.07(무시), 양끝 0.56점차 — **위험요인 뭉치면 신호 약함**.
  → 진짜 큰 웰빙 하락은 특정 요인(고립)에서 옴. 그래서 step5는 요인을 **뭉치지 말고 '고립' 정조준**.

## 5단계 · '고립' 정조준 — ✅ 확정

- **시각자료**: `outputs/figures/21_rested_isolation.png` (`scripts/rested_isolation.py`)
- 쉬었음 내부를 **isolation_flag 하나로만** 가름(고립 n=41, 3.9%).
- **웰빙**: 삶만족 6.49→**4.81**(Mann-Whitney p=2.4e-07, r=-0.47 큰효과), 행복감 6.67→4.87(r=-0.48), 주관계층(r=-0.33).
- **지원망**: 도움없음 7.6%→**33.2%**(Fisher 정확검정 p=1.07e-05, OR=5.77) → 고립자는 웰빙·지원망 **이중고**.
- **결론**: 쉬었음 내부 취약의 핵심 축 = **사회적 고립**(부채는 약함). 소표본이나 효과크기 커 방어 가능.
- **검정 주의**: 소표본 2x2는 **카이제곱(근사) 대신 Fisher 정확검정** 사용(D6).

## 6단계 · '연속 스펙트럼'도 성립 안 함 — ✅ 확정

- **시각자료**: `outputs/figures/22_rested_vuln_gradient.png` (`scripts/rested_spectrum.py`)
- 삶만족이 vuln_score(0~6)에 따라 6.60→6.42→6.18→5.78까지 내려가다 **4·5에서 반등(비단조)**, 6점 n=2.
- **Spearman rho=-0.09**(p=0.002): 유의하나 **사실상 무시할 수준**. 취약 '총량'은 웰빙 거의 설명 못 함.
- → **'군집'도 '스펙트럼'도 아님.** 내부 위험은 *양*(요소 개수)으로 환원 안 되고, **'종류'(고립)** 에 집중(step5 강화).

## 8단계 · 2022→2024 재현성 — ✅ 확정

- **시각자료**: `16_rested_share_2022_2024.png`, `17_rested_vuln_2022_2024.png`, `17b_rested_safety_net_2022_2024.png` (`scripts/compare_years.py`)
- **규모 재현**: 쉬었음 비중 5.2%→7.2%(가중), 모집단 약 52만→70만명 — step1 EAPS 증가추세와 **일관**(우연 아님).
- **취약 악화 일관**: 지원망 없음 3.5→8.4%, 부채 13.2→17.6%, 이자 9.5→13.5% — **모두 유의하게 악화 방향**(V≈0.10~0.13).
- **사적 안전망 약화(17b)**: 가족 도움 가능 95.4→85.1%(-10.3p), 지인 도움 13.9%(-14.2p), 부모 동거 78.7→75.0% — **버팀목이 얇아지는데** '도움받을 곳 없음'은 3.5→8.4%(+4.9p, 약 2.4배). 공공·민간 제도는 3~4%로 **무변(공백 지속)**. → 취약 증가의 원인이 '가족이 두꺼워서'가 아니라 **'가족마저 얇아지는데 제도는 비었다'**.
- **평균의 함정**: 평균 삶만족은 6.41→6.44로 **거의 불변(비유의)**. → 평균은 그대로인데 취약 소수 비중이 늘었다 = **내부 격차가 2년 새 더 벌어짐**(우리 핵심 논지와 정합).
- **정직한 한계(고립 제외)**: 외출빈도 문항이 2022는 **1~7점**, 2024는 **1~8점**으로 척도가 달라(2022 코드8 부재, 고립셀 n=3) 고립을 **연도 직접비교에서 제외**. 고립 효과는 2024 단년 횡단(step5)으로만 입증 — 시점 재현은 주장하지 않음.

| D9 | **연도 재현은 규모·부채·지원망으로, 고립은 제외** | 외출빈도 척도가 2022(1~7)·2024(1~8)로 달라 고립 연도비교 부적절(2022 n=3). 군집 재현(구 Fig18)도 D1로 폐기. 재현성은 코딩 동일한 지표로만 정직하게 주장 |
| D10 | **물가(CPI)를 안전망 약화의 '원인'으로 끌어오지 않음** | (1) 시점 2개뿐이라 통계적 인과 주장 불가(생태학적). (2) 물가 탓으로 돌리면 '일시적 외부충격'으로 프레이밍돼 **구조적 정책공백** 주장이 희석·위험도 축소. (3) 주관 '도움가능' 하락을 체감 문제로 깎아내릴 빌미. → 안전망 약화는 객관지표(도움없음·부채↑)로만 주장. 생활비 압박이 필요하면 외부 CPI 대신 내부 `has_living_cost_debt`(방법 B) 사용. 물가는 발표 배경 한 줄로만 |

| D11 | **KLIPS 제외 안 함 — '정직 축소'로 유지** | 공모전 필수조건(KOSSDA 소장 1건+)을 충족하는 우리 유일한 확인 KOSSDA 데이터가 KLIPS. 신뢰성 약한 부분(회고형 근로소득·비경활 식별)은 버리고, 방향만 보이는 가구부채 1지표만 보조검증으로 남김 |
| D12 | **외부 공식조사로 5단계 교차검증 보강** | 복지부 2023 고립·은둔 실태조사(3.7 vs 6.7)가 우리 미시결과(은둔없음 6.70·장기은둔 3.75)와 수렴 → 소표본 한계를 외부 타당도로 방어. 인과 아닌 '수렴' 주장만 |
| D13 | **고립 측정에 공식 '은둔기간'(seclusion_duration) 추가** | binary outing(7~8, n=41)보다 풍부(n=226)하고 용량반응(rho=-0.19~-0.25)이 보임. 단 2024 단년 → 연도비교엔 못 씀(D9 유지) |
